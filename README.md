# kana

日文練習小工具，純靜態網頁，開檔即用，可用 iPhone「加入主畫面」當 App 使用。

## 假名練習 — `index.html`

- 清音 / 濁音・半濁音 / 拗音 範圍自選
- 片假名、平假名兩種出題模式
- 羅馬拼音 / 平假名 / 片假名任一種輸入正確都算對
- 答錯有第二次機會，兩次都錯會記入錯題本（可隨時重練、清空）
- 🔊 日文語音朗讀、答錯震動回饋

## 單字卡 — `words.html`

「場所・存在」單元 77 個單字（中文 ・ 日本語 ・ 読み ・ 圖示）。

- 分組自選：存在・こそあど／場所／家・物品／人・動植物／位置／其他・會話
- **單字卡**：點一下翻面、左右滑動換卡、⭐ 標記已記住（會存起來）
- **選擇測驗**：看中文選日文、看日文選中文、聽發音選單字（四選一）
- 答錯自動進錯題本，可重練、清空
- 支援深色模式、鍵盤操作（空白鍵翻面、← →換卡、1-4 選答、Enter 下一題）

單字資料放在 `words.html` 裡的 `WORDS` 陣列，格式為
`[中文, 日本語, 読み, 分組, 圖示]`，要新增單字直接加一列即可。
